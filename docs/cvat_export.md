# Подготовка детекции для CVAT

Отдельный инструмент разметки, не этап рабочего pipeline. Не загружает модели и не запускает детекцию повторно. Требует Python 3.11+ и зависимости существующего проекта. Загружайте только собственные доверенные `.pkl`.

Предлагаемая структура в `D:\projects\ussr-ocr-table`:

```text
tools/dataset/export_detection_to_cvat.py
data/annotation/cvat/<название книги>/exports/
data/annotation/cvat/<название книги>/reviewed/
```

`exports` — пакеты предсказаний для отправки в CVAT; `reviewed` — скачанная и проверенная разметка. Исходные checkpoints сохраняем отдельно в `outputs`, как сейчас. Большие архивы и изображения в Git не добавляем.

После размещения скрипта в проекте запустите из его корня:

```powershell
.\.venv\Scripts\python.exe .\tools\dataset\export_detection_to_cvat.py ".\outputs\1953_F1562_Op11_D4479_ячмень\checkpoints\detection.pkl"
```

Название книги берётся из `Cell.document_name` в detection, не из имени папки. Из `data/processed/<название книги>.zip` берутся исходные изображения. Контрольная сумма ZIP сверяется с checkpoint. По умолчанию экспортируются все страницы detection, включая страницы без обнаружений.

Для выбора страниц добавьте, например:

```powershell
--pages 20231225_120940 20231225_120946
```

Другую папку назначения можно указать через `--output-dir`. Существующий архив не перезаписывается: для следующего экспорта выберите новую папку.

Внутри ZIP: `data.yaml`, `train.txt`, `images/train/*`, `labels/train/*.txt`, `export_manifest.json`. Название `train` здесь техническое, это не назначение проверяемых страниц в обучающую выборку. До проверки в CVAT разметка остаётся предсказанием, а не ground truth.

Изображения копируются без изменения размера и перекодирования. Классы общего пакета: `0 column_header`, `1 row_header`, `2 value`, `3 empty`. При подготовке обучения для отдельных моделей потребуется снова назначить их локальные номера классов.

## Импорт в CVAT

Создайте проект с четырьмя классами из списка выше. В меню проекта выберите импорт датасета, формат **Ultralytics YOLO Detection 1.0**, и загрузите ZIP. Это импорт датасета с изображениями, не загрузка `.pkl` и не восстановление резервной копии задачи.

Если используете задачу вместо импорта проекта: сначала загрузите в задачу изображения из `images/train`, затем импортируйте аннотации из ZIP в формате Ultralytics YOLO Detection. Названия классов должны совпадать.

Проверьте все ячейки каждой выбранной страницы: добавьте пропущенные, удалите лишние, исправьте границы и классы. Экспортируйте исправленный датасет с изображениями в `reviewed`. Подготовку обучающих патчей выполняем отдельно после проверки.

Формат: https://docs.cvat.ai/docs/dataset_management/formats/format-yolo-ultralytics/
