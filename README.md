# USSR Cargo Table Recognition

Проект по автоматизированной оцифровке исторических статистических таблиц СССР.

Проект выполняется в рамках проектной работы Яндекс для\
**Института истории и археологии Уральского отделения Российской академии наук (УрО РАН)**.

## О проекте

Цель проекта — разработка системы автоматического распознавания и восстановления структуры исторических таблиц, содержащих данные о межрегиональных грузопотоках по железнодорожной сети СССР.

Исходные документы относятся преимущественно к 1940–1950-м годам и представлены в виде фотографий и сканов архивных материалов.

Документы характеризуются неоднородным качеством изображений, сложной структурой таблиц, печатным и рукописным текстом, изгибами страниц, пустыми ячейками и многоуровневыми заголовками.

## Основные задачи

- обнаружение и классификация ячеек таблицы;
- распознавание печатного и рукописного текста;
- распознавание заголовков строк и столбцов;
- восстановление структуры таблицы;
- построение связей между значениями и соответствующими заголовками;
- нормализация распознанных названий;
- автоматическая проверка результатов распознавания;
- экспорт структурированных данных в JSON, CSV и XLSX.

## Технологии

В проекте используются:

- Python;
- Ultralytics YOLO;
- PaddleOCR;
- OpenCV;
- NumPy;
- pandas;
- Yandex AI Studio;
- мультимодальные языковые модели для проверки результатов OCR.

## Общая архитектура

```text
Исходное изображение
        ↓
Детекция элементов таблицы
        ↓
Классификация ячеек
        ↓
OCR / HTR
        ↓
Нормализация результатов
        ↓
Восстановление структуры таблицы
        ↓
Проверка спорных результатов с помощью LLM
        ↓
JSON / CSV / XLSX
```
